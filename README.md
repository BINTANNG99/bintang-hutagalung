# Bintang Hutagalung — Portfolio

Personal portfolio website for **Bintang Hutagalung**, Machine Learning Engineer & Data Scientist.

**Live:** [bintang-hutagalung.netlify.app](https://bintang-hutagalung.netlify.app)

---

## Tech Stack

- **Next.js 16** — App Router, multi-page
- **Tailwind CSS v4** — utility-first styling
- **Framer Motion** — animations
- **Gemini AI** — AI chat assistant
- **Netlify** — deployment

## Features

- Dark / Light mode
- Bilingual EN / ID
- AI chat powered by Gemini
- Live GitHub projects
- Neural network canvas
- Skill detail pages
- Download CV

## Run Locally

```bash
npm install
npm run dev
```

Create `.env.local`:

```
GEMINI_API_KEY=your_key_here
```

Get a free key at [aistudio.google.com](https://aistudio.google.com/app/apikey).
